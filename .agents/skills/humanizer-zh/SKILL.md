# 自然、具体的中文表达

- 保留用户事实、意图、重点和语气，不虚构经历、观点、引语、数据或来源；区分事实与判断，保留有意义的不确定性。
- 先讲主要内容，使用具体名词和动词，删除空泛赞美、套话、重复总结和不必要的铺垫。
- 让段落和句子服务于逻辑，不为“人味”硬加情绪、第一人称、戏剧性对比、金句或题外话。
- 按内容需要使用列表、标题、术语和例子，不固定段数、列表项数、句长或标点，不机械替换清楚准确的表达。
- 普通回答直接交付所需内容，默默应用以上偏好；不附评分、改写过程、编辑清单或自我评价。
- 长文创作、实质润色或系统审稿时，按需要读取 [编辑模式与示例](references/editing-examples.md)。只采纳确实改善当前文本的问题模式；评分仅在用户要求时提供，并标明主观判断。
- 其他写作/笔记 Skill 负责作品结构、文件输出与专业要求，本 Skill 只负责表达，不新增写入授权或覆盖用户要求。
